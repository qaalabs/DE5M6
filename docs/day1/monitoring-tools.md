# Monitoring Tools

**Learning Type:** Discussion  
**Format:** 2-3 learners share, ~2-3 mins each

## Opening Question

> "Before we break — what monitoring tools does your team actually use day-to-day?"

## Follow-up Prompts

- "What does it show you — pipelines, infrastructure, something else?"
- "How do you find out something's broken — alert, dashboard, someone tells you?"
- "Is there anything you wish it could do that it can't?"

## Facilitator Notes

- Take a mental note of tools mentioned — useful reference point during the cloud comparison at 14:50
- If nobody volunteers: "Does anyone use anything beyond what we just saw in Fabric?"
- If a tool comes up you don't know: "Has it worked well for your team?" — turn it back to them
- Keep it moving — this is a warm-up for the afternoon, not a deep dive
