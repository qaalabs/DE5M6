# Clone the M6 Files

!!! info "Before you start today's lab, you need the data files on your machine."

This is a public, read-only repo of course files - not something you'll commit or push to, just clone it once and work from the local copy.

!!! note "Already cloned this yesterday?"
    Some VMs reset overnight, so you may not have the `M6` folder anymore. If `M6` is still on your Desktop from Day 2, just check Step 4 below and skip the rest.

## Step 1: Open Terminal

Open **Terminal** on your Virtual Machine. It will open at: `C:\Users\Admin`


## Step 2: Navigate to your Desktop

```
cd Desktop
```


## Step 3: Clone the repository

```
git clone https://github.com/QAADE5/M6.git
```

This will create an `M6` folder on your Desktop.

```
cd M6
```


## Step 4: Confirm the files are there

```
dir
```

Check that the `M6` folder on your Desktop contains a `day3/` folder, with:

- `2019.csv`, `2020.csv`, `2021.csv`
- `metadata.json`

!!! success "You are ready to start"
