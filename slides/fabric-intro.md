# What is a Lakehouse?

| Data Lake | Data Warehouse |
|-----------|----------------|
| Scalable, distributed file storage | Relational schema modelling |
| Flexible schema-on-read | SQL-based querying |
| Big data technology compatibility | Proven basis for reporting |

A lakehouse combines both.
