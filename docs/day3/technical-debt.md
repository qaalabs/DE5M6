# Technical Debt Audit

**Learning Type:** Investigation  
**Format:** Groups audit a shared codebase, report back through a specialist lens

## Setup

- Repo: https://github.com/QAADE5/techmart-2026
- Learners use the checklist and Google Doc to record findings
- All groups audit all files - but each group has a **reporting lens**

## Group Lens Assignment

| Group | Lens            | Focus areas                                              |
|-------|-----------------|----------------------------------------------------------|
|   1   | Security        | Security issues + configuration management               |
|   2   | Performance     | Database performance + application performance           |
|   3   | Code Quality    | Hard-coded values + duplication + naming + code structure|
|   4   | Maintainability | Documentation + error handling + logging & monitoring    |

## Facilitator Notes

- Explain the disclaimers on the README - all credentials are fake, intentionally broken
- Show the repo briefly before sending to breakouts
- Google Doc is the shared record - everyone contributes findings
- Circulate through breakout rooms, steer groups who get stuck toward the checklist

## Report Back

Each group presents through their lens:

- "The most significant [security/performance/code quality/maintainability] issue we found was..."
- "Our priority fix would be... because..."
